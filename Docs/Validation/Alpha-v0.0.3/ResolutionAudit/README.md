# Window-size diagnostic

This final-code windowed run requested 2560 x 1440 but actually reported/rendered 1705 x 958. Every original metric, frame trace, capture and log is retained here. These data are not used as the report's 1440p results. The same binary was rerun with exclusive fullscreen requested; each accepted parent-directory record reports actual 2560 x 1440 and rendered/sample counts within one frame.

The original pre-polish baseline was windowed at actual 2560 x 1440. The display-mode difference is documented as a limitation of direct performance comparison.
