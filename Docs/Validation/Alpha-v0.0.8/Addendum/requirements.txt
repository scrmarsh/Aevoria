# 1. CRITICAL — REMOVE SQUARE AND MAZE-LIKE TERRAIN ARTIFACTS

The user has observed square patterns on virtually every terrain type, including completely flat grassland.

Mountain regions also exhibit unnatural square, maze-like ridges and trenches.

These are not acceptable natural terrain formations.

### Diagnose the actual source

Investigate:

- Global geological sampling.
- Heightmap interpolation.
- Regional terrain reconstruction.
- Coarse drainage grids.
- Erosion and uplift masks.
- Shader sampling.
- Terrain normals.
- Material blending.
- Clipmap sampling.
- Texture atlas filtering.
- Tile boundaries.
- LOD transitions.
- Any grid-aligned derivatives or processing steps.

Determine whether artifacts exist in the authoritative heightfield or only in rendering.

Create diagnostic captures that isolate geometry, normals, albedo, elevation, and material masks.

Do not merely blur terrain or hide the squares with additional noise.

### Required result

Grasslands should look continuous and naturally textured.

Mountains should have recognizable peaks, ridges, cliffs, slopes, and valleys.

No obvious checkerboard, rectangular, or maze-like generation patterns should remain.

Fix this before attempting additional mountain-height exaggeration.

# 2. CRITICAL — GOD-MODE ZOOM FAILURE

The user reports two related problems.

First, when zooming toward the ground, the scene sometimes turns gray and stops responding to further zoom input.

Second, God-mode zoom can sometimes pass directly through the terrain.

Both are critical camera defects.

### Required fixes

Investigate camera position, target height, near/far clipping, surface collision, camera altitude calculation, scene rendering, LOD availability, and input handling.

God-mode zoom must never:

- Pass beneath the ground unintentionally.
- Get stuck inside terrain geometry.
- Turn into a gray or empty screen.
- Lose the landscape when entering a new LOD.
- Stop accepting input because a terrain chunk is unavailable.
- Incorrectly calculate distance to the ground from sea level instead of local elevation.

Use authoritative terrain height and appropriate collision or clearance checks.

During zoom transitions, retain the previous usable terrain representation until replacement detail is ready.

Recover gracefully if a streaming operation fails.

### Acceptance

Test continuous zoom from the highest world overview to a few meters above ground level, including mountain peaks, valleys, grasslands, riverbanks, and coastlines.

Test rapid scrolling in both directions.

Test zoom while the terrain is still loading.

The camera must remain controllable.

# 3. EXPONENTIAL GOD-MODE ZOOM

The zoom system should cover enormous distances without becoming difficult to control.

Implement smooth logarithmic/exponential distance scaling.

The user wants to be able to inspect a location from around 50 meters above the terrain, then smoothly pull back toward hundreds of meters, kilometers, and eventually the full world.

Illustrative scale:

- 5–10 meters: close terrain inspection.
- 50 meters: local inspection.
- 500 meters: neighborhood-scale inspection.
- 5 kilometers: regional inspection.
- 50 kilometers: broad geographic inspection.
- Hundreds or thousands of kilometers: world overview.

These are scale references, not mandatory discrete jumps.

**Scrolling must remain smooth, not jump tenfold per mouse-wheel notch.**

Use multiplicative distance adjustment with interpolation.

At high altitudes, each zoom increment should cover more world distance.

Near the ground, zoom steps should become progressively finer.

Maintain a minimum clearance above the actual local terrain surface.

Camera collision must account for steep slopes and mountains.

Separate zoom distance from horizontal movement speed.

Do not allow high-altitude zooming to become sluggish.

Do not allow low-altitude movement to become nearly stationary.

# 4. CAMERA MOVEMENT SPEED

The user reports that movement becomes far too slow when zoomed close to the ground.

Adjust speed scaling to maintain useful control across large and small distances.

Provide sensible minimum movement speed so the camera does not become practically immobile.

Scale God-mode panning speed with altitude, while keeping the movement responsive close to terrain.

Include adjustable movement sensitivity and speed controls if suitable.

Movement and zoom must function smoothly together.

Preserve existing WASD, mouse look, middle-mouse drag, edge scroll, and other established controls.
