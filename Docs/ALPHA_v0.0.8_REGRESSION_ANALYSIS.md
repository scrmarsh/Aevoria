## Performance investigation

The v0.0.7 excavation maximum was 64.6593 ms, after 92 ms in v0.0.6. `LocalSolidField.Triangle` emits three new vertices per face (about 400,752 in the recorded sample); presentation copies these arrays and installs a synchronous MeshCollider. Worker-side indexing can reduce duplicate vertices without changing the scalar field or triangle winding. Collider installation and actual outliers must be measured again; neither a lower vertex count nor a successful test proves hitch removal.

## Executed follow-up diagnosis

The original audit preceded implementation. Later exact native-seed field probes separated raw height, carved height and rainfall. Horizontal overview bands persisted after compact-support hydrology eliminated lookup-cell steps; rainfall contained the matching long streaks. Independent one-row wind transport was therefore an additional confirmed cause. Climate 3 adds physical crosswind moisture exchange and smooth prevailing-direction transitions. Before/after numeric rasters and field-probe PNGs remain in Validation/Alpha-v0.0.8.

A controlled native excavation measured a 49.73 ms frame with 48.35 ms installation, including 43.28 ms synchronous collider assignment. This confirmed collider cooking as the dominant measured install cost. The follow-up pre-bakes immutable meshes in one Unity job, holds the old collision/mask until publication and completes owned work before cleanup. Final measurements must verify the resulting cost; code alone does not establish hitch removal. The complete earlier run remains in Rendered-final-pre-climate.

A second native artifact probe held the Medium seed/camera fixed. Direct shadows, inland water and vegetation could each be disabled without removing the repeated bank pattern. Flat local normals removed it; zero bank attributes did not. This confirms an additional normal-frequency problem in WorldRenderer.GeneratePayload: a fixed two-metre derivative was shaded on much coarser LOD geometry. Interior normals now use mesh spacing and retain common border normals. Raw probe captures preserve the evidence; diagnostic hiding is not a production solution.

The local 257-square/16 m physical probe refined that diagnosis: raw heights were smooth but carved slopes contained the repeated fan. Changing local normals exposed continuous stripes rather than removing the physical source. An exhaustive polyline search and smooth water-level interpolation alone did not remove the entire fan. Hydrology 4 therefore queries a smooth bounded centreline, retaining all original path samples and using the shared monotone level curve. The repeated fan disappears in the final numeric slope raster. Native follow-up is required before classifying the visible repair. Interrupted intermediate validation remains under the interrupted-polyline4 names and is not reported as passing final evidence.
