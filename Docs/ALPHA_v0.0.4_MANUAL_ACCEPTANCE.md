# Alpha v0.0.4 manual acceptance — pending

No physical-input acceptance is asserted by the automated probes. Sean can review the Windows build using this checklist; earlier v0.0.3 items remain carried forward.

- Launch normally: Home appears promptly, no world generation starts, and an empty library has no invented recents.
- Create: type/edit a long name and seed, randomize, select each size, move mountain relief through 3,200 m, vary land/sea/climate, and confirm validation remains legible.
- World: WASD/Shift, mouse orbit/pan, wheel focus/zoom, optional follow/clearance, alt-tab and button-release behavior. Check the compact bar, Escape pause menu and F3 diagnostics. Interacting with menus must not move the camera.
- Save: advance several years, pause/set speed, save, return, quit/relaunch, load, then confirm year/day/pause/speed and continued simulation. Save As must create a separate GUID even with a shared name.
- Archive: search/sort, inspect details, rename, cancel deletion, confirm deletion of a disposable world only. Check recents against real files.
- Settings: Apply/Cancel/Defaults, VSync/cap, quality/shadows/FXAA/blur, camera options and autosave. Change display mode/resolution and test Keep, Revert, Escape, navigation away, timeout and alt-tab. Never accept an unusable display solely because a scripted test passed.
- History: browse every Changelog version and Chronicle chapter, scroll to the bottom, and distinguish the retained prophecy from Book IV's current ledger. Check About wording.
- Geography: inspect the whole perimeter and low coast angles; no straight rectangular decorative land border should appear. Compare ridge profiles, plains and climate contrast with the supplied references.
- Inland water: examine tributary joins, downstream widths, channel/bank agreement, lake shorelines and outlets, and any naturally occurring steep-drop ribbons. Note coarse-grid turns or surface/LOD intersections.
- Vegetation/weather: confirm no trees occupy open water, compare wet/arid/cold regions, advance seasons, inspect rain/snow/fog/storm feedback and pause/resume continuity.
- Streaming: move rapidly through forests/coasts, change zoom repeatedly, watch for gaps, shimmering, skirts, silhouettes and the earlier bright horizon sliver. Run a longer session than the automated one-minute motion sample; monitor resource growth and presentation pacing.
- Exit: Save + return, Save + exit, and window close. Simulate a failed save only with a disposable archive and verify the world stays open with a useful error.

Recovery, unsupported-version and interrupted-write fault injection are covered by isolated automated tests; never damage a real world to satisfy this checklist. Full migration tooling, endorheic water balance, erosion, advanced ecosystems and civilization gameplay are outside this build.
